# Voice2Note — Feature Inventory (`REQ-1.1`)

> **Build verified:** Pure Java + Android XML Views (`com.example.cs265final`), compiled and tested on 2026-11-17.

## Essential In-Scope Functions

| Function ID | Function Name | Screen / Layout | User Input / Action | Observable Output / Result | Evidence |
|---|---|---|---|---|---|
| F-01 | Home Overview & Quick Launch | `HomeView` (`view_home.xml`) | Tap Start Recording, Upload Audio, New Note, View All, or a recent note card | Navigates to Recording, opens document picker, opens Library, or opens Note Detail; displays up to 3 recent notes or empty card | `evidence/screens/01-home-thai.png`, `03-home-with-note.png` |
| F-02 | Live Thai Speech-to-Text & Draft Composer | `RecordingView` (`view_recording.xml`) + `SpeechCaptureController` | Grant/deny `RECORD_AUDIO`, tap Mic, speak Thai (`th-TH`) or edit transcript, pick mood & folder, tap Save | Streams partial & final Thai text into editable transcript, records PCM to MP3 on API 33+ (or legacy speech intent below API 33), validates non-empty transcript and stopped mic before saving | `evidence/screens/02-recording-composer.png`, `RecordingViewTest`, `SpeechDraftTest` |
| F-03 | Note Detail, Rename, Copy, Share & Playback | `NoteDetailView` (`view_note_detail.xml`) | Tap note card; tap Edit/Rename, Move Folder, Copy, Share, Play/Attach Audio, or Delete | Displays title, date, mood, folder, body, and audio bar; validates non-blank title on rename; copies to clipboard; launches share chooser; plays attached audio with pause on `ON_STOP` | `evidence/screens/07-note-detail.png`, `CalendarAndDetailTest`, `NoteDetailLifecycleTest` |
| F-04 | Safe Note Deletion | `DeleteNoteConfirmation` (`dialog_delete_note.xml`) | Select Delete from card `⋮` menu or Detail `⋮` menu; tap Cancel or Delete | Shows confirmation dialog; Cancel preserves note; Delete removes note, cancels any pending WorkManager job, and deletes orphaned managed recording files | `evidence/screens/08-delete-confirm-dialog.png`, `DeleteNoteConfirmationTest`, `MainActivityFlowsTest` |
| F-05 | Library & Folder Organization | `LibraryView` (`view_library.xml`) + `FolderDialogs` | Filter by source (`All`, `Recorded`, `Uploaded`), create/rename/delete folder, tap folder card, or move a note to another folder | Persists folders separately from notes; validates non-empty/non-duplicate folder names; renaming updates all assigned notes; deleting confirms and moves notes to fallback folder (`ทั่วไป`); **Folders group notes and are distinct from ordered audio playlists** | `evidence/screens/04-library-folders.png`, `NoteStorageTest`, `CompatibilityAndFolderTest` |
| F-06 | Scoped Search | `SearchView` (`view_search.xml`) + `SearchControls` + `NoteFilters` | Type title/body query (Thai or English) and select folder scope in `Spinner` | Filters notes case-insensitively and trims Unicode spaces; displays match count and empty states (`no notes yet` vs `no matching notes`); tapping a result opens Note Detail | `evidence/screens/06-search-scoped.png`, `NoteFiltersTest`, `SearchControlsTest`, `MainActivityFlowsTest` |
| F-07 | Daily Journal Calendar | `CalendarView` (`view_calendar.xml`) | Switch months (`‹`/`›`), tap `Today`, tap any date cell, or tap `+` | Marks dates containing notes with indicator dots, highlights selected day, lists notes for that date or shows empty state | `evidence/screens/05-calendar-journal.png`, `CalendarAndDetailTest` |
| F-08 | Dedicated Audio Playback | `PlaybackView` (`view_playback.xml`) | Launch playback after home audio upload; scrub `SeekBar` or tap Play/Pause | Prepares audio via `MediaPlayer`, updates `SeekBar` and `m:ss` timer, pauses on `ON_STOP` preserving position | `PlaybackViewTest`, `WavFileTest` |
| F-09 | Background Audio Upload & Transcription | `TranscriptionWorker` + `TranscriptionClient` + `TranscriptionScheduler` | Tap Upload Audio on Home and pick MP3/M4A/WAV | Persists URI permission, creates `QUEUED` note, runs `WorkManager` upload & polling (`POST /api/v1/transcriptions`, `GET .../jobId`), reconciles result without overwriting UI edits, supports Retry on failure | `TranscriptionClientTest`, `TranscriptionTextTest`, `NoteStorageTest` |
| F-10 | Compatibility, Navigation & Lifecycle | `MainActivity`, `res/values-*`, `res/layout-sw600dp/` | Rotate screen, switch `th`/`en`, switch Day/Night, use tablet width (`sw600dp`), press Back, background app | Preserves draft/tab/selection across rotation; switches Thai/English & Light/Dark; adapts to tablet navigation rail; Back navigates cleanly and guards unsaved drafts & app exit | `evidence/device-compatibility/`, `RecordingDraftTest`, `MainActivityFlowsTest`, `CompatibilityAndFolderTest` |
