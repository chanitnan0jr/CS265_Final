## 2. Connections to Other Courses (`REQ-1.4`)

1. **Operating Systems — Concurrency, Mutual Exclusion & Background Scheduling:**
   - **Application:** `NoteStorage.java` serializes concurrent read-modify-write cycles between the UI thread (`MainActivity`) and background `WorkManager` worker threads (`TranscriptionWorker`) using a process-wide monitor lock (`synchronized (LOCK)`), while `savePreservingTranscriptions()` merges finished worker transcripts without overwriting concurrent UI title/folder edits.
   - **Audio Threading:** `SpeechCaptureController.java` runs a dedicated daemon thread (`Voice2NoteMicTee`) streaming PCM chunks from `AudioRecord` through a `ParcelFileDescriptor` pipe (`createPipe()`) to `SpeechRecognizer` on API 33+, with atomic cancellation (`AtomicBoolean`) and `Thread.join(200)` cleanup on stop.
   - **Files:** `NoteStorage.java`, `TranscriptionWorker.java`, `SpeechCaptureController.java`, tested by `NoteStorageTest.uiSaveKeepsAWorkerTranscriptionResult()` and `aStaleWorkerCannotUpdateAReplacementJob()`.

2. **Database / Information Systems — Schema Evolution & Referential Integrity:**
   - **Application:** Even without SQLite, `NoteStorage` + `FolderStorage` enforce primary-key identity (`noteId` UUID instead of mutable titles/timestamps), backward-compatible schema migration (inferring `AudioSource` from legacy `file:`/`content:` URIs and generating deterministic UUIDs for pre-migration records), fail-closed corruption handling (throwing `JSONException` instead of overwriting), and cascading updates when renaming or deleting folders (`NoteRepository.renameFolder()`, `deleteFolder()`).
   - **Files:** `Note.java`, `NoteStorage.java`, `FolderStorage.java`, `NoteRepository.java`, tested by `NoteStorageTest`.

3. **Digital Signal Processing / Multimedia Systems (Applied Computing):**
   - **Application:** `AudioUtils.java` writes RIFF WAV headers, performs windowed-sinc mono PCM resampling (`resampleMonoPcm16`) to 16 kHz, decodes legacy AMR/audio URIs via `MediaExtractor` + `MediaCodec`, and encodes 16-bit PCM buffers to MP3 via `jump3r` (`Lame`), verified in `WavFileTest`.
