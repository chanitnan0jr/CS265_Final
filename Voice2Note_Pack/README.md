# Voice2Note Pack

This package contains the core planning and design files for the **Voice2Note** project.

## Included files

- `Roadmap-Plan.md` — product roadmap, milestones, development phases, testing, and documentation plan.
- `Design-Scheme.md` — visual design direction, UI principles, color system, typography, icon style, and mobile screen guidance.
- `example-picture.png` — example concept image for the app direction.

## Product summary

**Voice2Note** is a mobile-first Thai speech-to-text journaling and note app focused on:

- Live Thai speech-to-text
- Emotional journaling / venting notes
- MP3 upload and async transcription
- Searchable notes and folder organization
- Future karaoke-style transcript sync and scoped search / RAG

## Recommended use

Use this pack as the starting point for:
1. Product planning
2. Figma/UI implementation
3. Android frontend development
4. Milestone tracking
5. Team onboarding
