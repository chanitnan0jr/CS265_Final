# CS265 — BM05: Providing Alternative Resources

> **Source:** `BM05(1).pdf` (48 หน้า), ปีการศึกษา 2569 · อ้าง `CS265 BM05, slide N`  
> **Purpose:** ใช้อ้างเนื้อหาวิชา (`REQ-1.3`) ไม่ใช่หลักฐานว่าแอปพัฒนา/ทดสอบผ่านแล้ว

## Core concepts

1. **Mobile capabilities & storage (หน้า 2–4):** Touch events, sensors, image/audio/video, media framework, local files, preferences, SQLite และ online databases เป็นภาพรวมความสามารถของ Android; ไม่ใช่ tutorial implementation รายฟีเจอร์.
2. **Resource system (5–6, 12–17):** เก็บทรัพยากรใน `res/`: `drawable/` (ภาพ), `mipmap/` (icons), `layout/` (UI), `menu/`, `raw/` (media), `values/` (strings/colors/dimens/themes). อ้างผ่าน `R.string.name` ในโค้ด หรือ `@string/name` ใน XML; `assets/` ใช้อ่าน raw files ผ่าน `AssetManager`.
3. **Centralized UI values (7–11):** แยกข้อความ สี ระยะห่างและ style/theme ไว้ใน resources (`strings.xml`, `colors.xml`, `dimens.xml`, `themes.xml`). ใช้ `dp` สำหรับขนาด UI และ `sp` สำหรับขนาดตัวอักษรตาม setting ผู้ใช้; หลีกเลี่ยง hard-coded `px`.
4. **Alternative resources (18–23, 37–41):** สร้าง `res/<type>-<qualifiers>/` โดยใช้ **ชื่อไฟล์ resource เดียวกับ default**; Android เลือก best match ตาม configuration และ fallback ไปยัง resource ที่ไม่มี qualifier. เมื่อมีหลาย qualifiers **ต้องเรียงตามลำดับสไลด์ 20–23**, ห้ามซ้อน directory และควรมี default ครอบคลุม.
5. **Localization & theme (20, 22, 25–28, 42–45):** `values-th/` สำหรับข้อความภาษาไทย; `values-en-rUS/` สำหรับภาษาอังกฤษตาม region; BCP 47 เช่น `values-b+zh+Hant+TW/` (26). มี qualifiers สำหรับ RTL (`ldrtl`), Night/Day (`night`/`notnight`), orientation (`land`/`port`). สไลด์ 42 แสดง `res/values-th/` เป็นตัวอย่าง localization.
6. **Multiple screen layouts (29–36, 46):** `sw600dp` คือ **smallest width** ซึ่งไม่เปลี่ยนเมื่อหมุนเครื่อง; `w<N>dp`/`h<N>dp` คือขนาดพื้นที่ปัจจุบันที่เปลี่ยนตาม orientation. ตัวอย่าง 1/2/3 คอลัมน์: `layout/`, `layout-sw600dp/`, `layout-sw800dp/` (46). Density `ldpi/mdpi/hdpi/xhdpi/xxhdpi` ช่วยเลือก bitmap ให้เหมาะสม (22, 33–36).

## Resource directory examples

```text
res/
├── layout/activity_main.xml            # default
├── layout-sw600dp/activity_main.xml    # >=600dp smallest width
├── layout-sw800dp/activity_main.xml    # >=800dp smallest width
├── values/strings.xml                  # fallback / default
├── values-th/strings.xml               # Thai localization
└── drawable-hdpi/icon.png              # image for hdpi screens
```

ตัวอย่างผสานรูปแบบจากหน้า 5–6, 18–22, 29, 33, 42, 46; ไม่ใช่โครงสร้างที่ทุกโปรเจกต์ต้องใช้. ตัวอย่างหลาย qualifiers จากแบบฝึกหัด: `layout-th-sw720dp-land/` (45).

| `REQ-2.2–2.4` | Resource mismatch/fallback (37–41) | ต้องมีปัญหาที่พบจริง → root cause → fix → before/after |

**Project application (ไม่ใช่เนื้อหา implement จากสไลด์):** แอปโน้ตเสียง Android/Kotlin อาจใช้ `values-th/` สำหรับข้อความ, adaptive layout ตามขนาดจอ และสีสำหรับ Day/Night. ถ้าใช้ **Jetpack Compose** สามารถใช้วิธี responsive/theme ของ Compose โดยอ้าง BM05 ที่ **ระดับแนวคิด** ไม่อ้างว่า slides สอน Compose implementation.

**AI guardrails:** มี resource qualifiers ≠ ผ่าน rubric; ต้องมีหลักฐานทดสอบจริง. BM05 ไม่ได้สอนวิธี restore Activity state เมื่อสลับแอป (ใช้ BM02/BM06 เป็น reference แยก). อย่าสร้างผลการทดสอบหรือ bugs ขึ้นมาเอง.
