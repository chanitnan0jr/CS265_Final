# CS265 — BM06: Handling Runtime Changes

> **Source:** `BM06.pdf` (12 หน้า), ปีการศึกษา 2569 · อ้างอิง `CS265 BM06, slide N`  
> **Purpose:** เป็น *context เนื้อหารายวิชา* สำหรับ `REQ-1.3` ไม่ใช่หลักฐานว่าโปรเจกต์ผ่านการทดสอบแล้ว

## Core concepts

1. **Configuration change & Activity recreation (หน้า 2):** เมื่อ configuration เปลี่ยน เช่น orientation, ขนาดพื้นที่แสดงผล, locale, ขนาด/น้ำหนักตัวอักษร และ light/dark UI mode โดยปกติ Android จะสร้าง Activity ใหม่ (`onDestroy()` → `onCreate()`). ตัวแปรในหน่วยความจำและค่าที่ผู้ใช้กำลังแก้ไข **เสี่ยงสูญหายหรือกลับเป็นค่าเริ่มต้น** หากไม่ได้จัดการ state.
2. **`android:configChanges` (หน้า 3–6):** ระบุใน `AndroidManifest.xml` ว่า Activity จะ *จัดการการเปลี่ยนแปลงชนิดนั้นเอง* แทนการ recreate ตามปกติ; ระบบเรียก `onConfigurationChanged(newConfig)`. ตัวอย่างชนิดที่สไลด์กล่าวถึง: `locale`, `fontScale`, `uiMode`, `orientation`, `screenSize`, `screenLayout`, `smallestScreenSize`, `layoutDirection`, `density`, `colorMode` รวมถึง `mcc`/`mnc`. การเลือกใช้ต้องจัดการการปรับ UI เองให้ครบ ไม่ใช่เพียงใส่ Manifest แล้วถือว่ารองรับ.
3. **Locale + font scale example (หน้า 7–8):** ตัวอย่าง Manifest ใช้ `android:configChanges="locale|fontScale"` และ callback อ่าน `newConfig.fontScale` เพื่อเปลี่ยนขนาดข้อความ; ภาพเปรียบเทียบภาษาอังกฤษ → ไทยและ font size ที่โตขึ้น.
4. **Font-size choice dialog (หน้า 9–12):** อีกตัวอย่างตั้ง `android:configChanges="fontScale"` และใช้ `onConfigurationChanged()` แสดง Dialog เลือก `Use System`, `Keep Original` หรือ `2×` ก่อนเรียก `applyFontScale(...)`; ภาพก่อน/หลังแสดงการเปลี่ยนขนาดตัวอักษรโดย UI ยังใช้งานได้.

## Mechanism / selection

```text
Device configuration changes
├─ Default behavior: Activity recreated → ต้องดูแล state และ UI ที่สร้างใหม่
└─ Declare relevant android:configChanges
   → Activity handles change → onConfigurationChanged(newConfig)
   → อัปเดต UI/resources/state ให้สอดคล้องกับ configuration ใหม่เอง
```

**อย่าสับสน:** *Configuration change* (BM06) ไม่ใช่เหตุการณ์เดียวกับ *switch app to background / resume* (`REQ-4.4`, BM02). การจัดการ rotation/locale/font scale เพียงอย่างเดียว **ยังไม่พิสูจน์** ว่าหยุดงานเมื่อสลับแอปและกลับมาทำงานต่อได้.
