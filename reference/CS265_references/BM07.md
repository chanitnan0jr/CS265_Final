# CS265 — BM07: Input Controls

> **Purpose:** AI ใช้เป็น *เนื้อหารายวิชา* สำหรับ `REQ-1.3` เท่านั้น; ไม่ใช่หลักฐานว่าโปรเจกต์ implement หรือผ่านการทดสอบแล้ว

## Core concepts

1. **Input controls (หน้า 2–3):** Android มี `Button`, `EditText`, `CheckBox`, `RadioButton`, `Switch`, `Spinner`, `Picker`, `RatingBar`. ตัวอย่าง *My Weekend Planner* สาธิตฟอร์มที่รวมหลาย control.
2. **Button / EditText (หน้า 4–5):** Button แบบข้อความหรือภาพ; `EditText` ใช้ `hint` และ `inputType` เช่น `text`, `textMultiLine`, `numberDecimal`, `textEmailAddress` เพื่อให้คีย์บอร์ดและการรับค่าเหมาะกับงาน; label อ้าง `@string/...`.
3. **Autocomplete / Radio / Checkbox (หน้า 6–10):** `AutoCompleteTextView` + `ArrayAdapter` แนะนำค่าจาก `string-array` โดยกำหนด `setThreshold(1)`; `RadioGroup` เลือกได้หนึ่งค่า (`getCheckedRadioButtonId()`, `-1` หมายถึงไม่เลือก); `CheckBox.isChecked()` ใช้รวมหลายตัวเลือก.
4. **Spinner (หน้า 11–12):** รายการแบบ dropdown ใช้ `ArrayAdapter.createFromResource(R.array...)`; อ่านค่าด้วย `getSelectedItem()`. ตัวอย่างกำหนดความสูงขั้นต่ำ `48dp`.
5. **Date / Time Picker (หน้า 13–18):** ปุ่มเปิด `DatePickerDialog` / `TimePickerDialog`; callback รับวันที่/เวลา และจัดรูปแบบด้วย `SimpleDateFormat` กับ `Locale.getDefault()`.
6. **Switch / RatingBar (หน้า 19–20):** `SwitchCompat.isChecked()` ใช้สถานะเปิด/ปิด; `RatingBar.getRating()` อ่านคะแนนและตั้งจำนวนดาว/step ได้.
7. **iOS input types & exercises (หน้า 21–23):** ตัวอย่างคีย์บอร์ด iOS และโจทย์เลือก UI control ให้เหมาะกับประเภทข้อมูล ไม่ใช่บทสอน Android implementation เพิ่มเติม.

**Mechanism:** `User action → read input/selection → validate/process → update result or invoke feature`.

## Voice2Note mapping (ข้อเสนอ ไม่ใช่สิ่งที่ตรวจพบในโค้ด)

- `EditText`: ตั้งชื่อ/แก้ไข Note และรับคำค้นหา (หน้า 5); `Spinner`/Radio: เลือก Folder เดียว; `CheckBox`: เลือกหลาย Tags **ถ้ามีฟีเจอร์นี้** (หน้า 7–12).
- `Switch` และ Date/Time Picker: ตั้ง Reminder **เฉพาะถ้าอยู่ใน Scope** (หน้า 13–19).
- **ข้อจำกัดของการอ้างอิง:** BM07 สอน `AutoCompleteTextView` แนะนำค่าจากตัวเลือก ไม่ได้สอน Full-text Search, Database Indexing หรือ Speech-to-Text. ตัวอย่าง Java/XML ไม่ได้บังคับให้ใช้ Java แทน Kotlin.
