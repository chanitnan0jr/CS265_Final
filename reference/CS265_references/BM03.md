# CS265 — BM03: Layout Alignment Guidelines

> **Source:** `BM03(1).pdf` (17 หน้า), CS265 ปีการศึกษา 2569  
> **Purpose:** ใช้อ้างอิง `REQ-1.3`; อ้างเป็น `CS265 BM03, slide N`  
> **Rule:** เนื้อหาสไลด์ไม่ใช่หลักฐานว่าฟีเจอร์ในโครงงานพัฒนา/ทดสอบสำเร็จแล้ว

## Key concepts

1. **Android Studio project** (หน้า 2–6): ตัวอย่างสร้าง **Empty Views Activity** เลือกชื่อ/package, ภาษา **Java**, Minimum SDK; แยก `AndroidManifest.xml`, Activity code, Layout XML, `strings.xml`, APK; รันผ่าน **Emulator** หรือโทรศัพท์จริง
2. **UI widgets** (หน้า 7–8): ใช้ `TextView`, `EditText`, `Button`, `ImageView`, `Switch`, `CheckBox` และ Layout containers ให้เหมาะกับการรับ/แสดงข้อมูล
3. **Code, XML & dimensions** (หน้า 9): Activity code ควบคุม behavior (`findViewById`); XML กำหนด View, ID, `android:text="@string/..."`; `wrap_content` = ขนาดตามเนื้อหา, `match_parent` = ตาม parent; ใช้ **dp** แทนการ hardcode pixels
4. **Layout types** (หน้า 10–12): `LinearLayout` เรียงแนวตั้ง/นอน, `RelativeLayout` วางสัมพันธ์กับ View อื่น, `ConstraintLayout` ยึด constraints ระหว่าง View/parent; หน้ายาวใช้ `ScrollView`; ตัวอย่าง nested `LinearLayout` (หน้า 11)
5. **Jetpack Compose** (หน้า 13–14): ตัวอย่าง UI เดียวกันด้วย `@Composable`, `Row`, `Column`, `Modifier`, `Button`, `Text`, `weight` และ `padding`; ภาพ Preview หลายรูปทรงหน้าจอ
6. **Layout validation** (หน้า 12, 15–16): ฝึกตรวจ Layout Validation, แยกข้อความไว้ที่ `strings.xml`, ใช้ `wrap_content`/`match_parent` หรือ `0dp` + `weight` โดยไม่ fix ขนาด pixel
7. **Multiple-device resources** (หน้า 17): ตัวอย่าง XML layout แยกตาม smallest-width: `layout/` (1 column), `layout-sw600dp/` (2), `layout-sw800dp/` (3)

## Rubric mapping

| Rubric | แนวคิด BM03 | หลักฐานที่ต้องทดสอบ/เก็บจริง |
|---|---|---|
| `REQ-1.3` | Layouts + resources (หน้า 7–17) | อ้างเลขหน้า, ระบุไฟล์โค้ด/หน้าจอที่นำไปใช้ |
| `REQ-3.1` | `dp`, layout strategy, validation, `sw...dp` (9–12, 17) | Screenshot 2 ขนาด/ความละเอียด; ปุ่มและข้อความไม่ถูกตัด/ซ้อน |
| `REQ-3.2` | Layout สำหรับหน้าจอหลายรูปทรง (14, 17) | ทดสอบ portrait/landscape หรือการล็อกแนวตาม Rubric |
| `REQ-3.3` | ข้อความใน `strings.xml` (4, 9, 15–16) | เพิ่มภาษาไทย/อังกฤษและทดสอบเปลี่ยนภาษา (สไลด์ไม่ได้สอนวิธีทำครบ) |
| `REQ-2.2–2.4` | ปัญหา responsive layout **อาจ** เป็น challenge | ต้องมีปัญหาจริง → สาเหตุ → จุดแก้โค้ด → ภาพก่อน/หลัง |

**Example application (ไม่ใช่เนื้อหาสไลด์):** แอปจดโน้ต Android/Kotlin เลือกใช้ XML หรือ Compose เพื่อทำหน้ารายการ/หน้าแก้ไข responsive; แยก UI wording เป็น resources แล้วทดสอบหลายขนาดจอ

**AI guardrails:** BM03 แสดงทั้ง **Java/XML Views** และ **Jetpack Compose** ไม่ได้กำหนดว่าต้องใช้แบบใด; `sw600dp`/`sw800dp` เป็นตัวอย่าง ไม่ใช่ requirement บังคับ; อย่าอ้างว่า BM03 สอน locale switching, day/night theme หรือ lifecycle โดยละเอียด; อย่าสรุปว่าผ่าน Rubric หากยังไม่มีผลทดสอบ
