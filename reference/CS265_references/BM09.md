# CS265 — BM09: Course Project Planning and Requirements

> **Source:** `BM09.pdf` (9 หน้า; หน้าปกระบุ BM09) · อ้าง `CS265 BM09, slide N`  
> **Scope:** หลักการวางแผนโครงงานและจัดหลักฐานรายงาน ไม่ใช่หลักฐานว่าแอปทำงาน/ทดสอบผ่านแล้ว

## Core concepts

1. **Use Case Diagram (หน้า 2):** ระบุ *Actor* (บทบาทผู้ใช้) และ Use Case เป็นคำกริยา เช่น เพิ่ม/แก้ไข/ลบ; สามารถรวมเป็น “จัดการ” เพื่อแสดงขอบเขตระบบโดยไม่ลงรายละเอียดเกินไป.
2. **Use Case Specification (หน้า 3):** ประกอบด้วย `Name`, `ID`, `Actor`, `Description`, `Pre-conditions`, `Post-conditions`, `Basic Flow`, `Alternative Flow` (เช่น ยกเลิก, ข้อมูลผิด/ซ้ำ). **สไลด์แนะนำให้เขียนรายละเอียดเฉพาะกรณีใช้งานที่ซับซ้อน** ไม่ต้องครบทุก Use Case.
3. **UI & screen descriptions (หน้า 4–6):** ตัวอย่าง Android Sunflower ใช้ **Tab** แบ่งหมวด และ **RecyclerView/CardView** แสดงรายการ; ตัวอย่าง Speech Billing มีหน้าผลลัพธ์และเมนู. รายงานควรมีภาพหน้าจอพร้อมอธิบายองค์ประกอบและ action เช่น card, tab, filter.
4. **Testing & deliverables (หน้า 7–8):** ทดสอบ **Positive**, **Negative**, **Boundary/Validation**; ตัวอย่างการประเมินความง่ายใช้จำนวนครั้งที่แตะ. ตาราง Test Case มี `TC ID | Scenario | Preconditions/Test Data | Expected | Actual | Pass/Fail`; ค่า Actual ต้องมาจากการทดลองจริง.
5. **Screen flow (หน้า 9):** จัดภาพรวมหน้าจอเป็น **เส้นเรื่องหลักและเส้นเรื่องย่อย** พร้อมลำดับ/ลูกศรการกระทำ ตั้งแต่หน้าตั้งต้นไปจนถึงผลลัพธ์.

## Voice2Note example (ข้อเสนอ ไม่ใช่ข้อเท็จจริงจากโค้ด)

- **Use Cases:** Record/Transcribe, Save/Edit/Delete Note, จัด Playlist/Folder, Search; เลือกเขียน Specification สำหรับ workflow ซับซ้อน (หน้า 2–3).
- **Main flow:** Home → Record → Transcript → Save → เปิด Note จากรายการ → แสดงผล โดยใช้ Screenshot ของแอปจริงและกำกับแต่ละ action (หน้า 9).
- **Test Cases:** บันทึกสำเร็จ (positive), ข้อมูลไม่ถูกต้องหรือการบันทึกที่ควรถูกปฏิเสธ (negative), ค่าว่าง/ขอบเขตความยาว/ไม่พบผลค้นหา (boundary ตามข้อกำหนดที่ทีมตกลง) พร้อม Actual จริง (หน้า 7–8).
- **ข้อจำกัด:** BM09 ให้แนวทางออกแบบ Use Case และทดสอบ **ไม่ได้สอนวิธี Implement Search, Folder หรือ Speech-to-Text**; ส่วน SQLite CRUD อยู่ BM08.
